# pragma_design_system

Sistema de diseño Flutter con componentes reutilizables (atoms, molecules, organisms, templates, theme).

Estructura principal:

- `lib/` — componentes y export principal.
- `pubspec.yaml` — dependencias y metadatos.

Instrucciones rápidas:

1. Instalar dependencias:

```bash
flutter pub get
```

2. Usar el paquete localmente desde otro proyecto añadiendo la ruta al `pubspec.yaml`.
