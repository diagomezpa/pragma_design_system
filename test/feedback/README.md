# Tests de FEEDBACK

Utilidades del sistema para mostrar retroalimentación al usuario.

## Componentes a testear:
- **AppSnackbar** - Mensajes temporales (success, error, info)
- **AppDialog** - Diálogos modales con acciones

## Estrategia de testing:
- ✅ Mostrar tipos de snackbar (success/error/info)
- ✅ Renderizado de diálogos con título/contenido
- ✅ Ejecución de acciones en botones
- ✅ Comportamiento de dismissing
- ✅ Integración con MaterialApp y context
