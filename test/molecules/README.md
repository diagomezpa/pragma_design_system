# Tests de Componentes MOLECULES

Componentes compuestos que combinan atoms para crear funcionalidades más complejas.

## Componentes a testear:
- **AppFormField** - Campo de formulario con label, hint, error states
- **AppCard** - Contenedor de superficie con interactividad opcional
- **AppSection** - Sección con título, descripción y contenido

## Estrategia de testing:
- ✅ Renderizado de elementos hijos
- ✅ Composición correcta de atoms
- ✅ Estados de error y validación
- ✅ Interactividad (onTap, onChanged)
- ✅ Título/descripción opcionales
